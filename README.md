# Osteon

Anatomy revision app: a 3D skeleton with muscles, ligaments, vessels and nerves,
origin and insertion highlights, a muscle lab with clinical links and mnemonics,
quizzes and spaced review.

Made by Yusuf Butt (King's College London, MBBS 2031). Free for KCL 2031.
